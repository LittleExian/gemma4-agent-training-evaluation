## 方法与比较条件

- 基模：`google/gemma-4-31B-it-qat-w4a16-ct`，原始打包W4权重，无LoRA。
- 三轮均为 `seed=42`、top-k64、temperature0.2、top-p0.95、thinking4096、最大输出8192、上下文32768。
- 每题8分钟、28次工具调用、80轮；工具超时240秒、官方验证超时300秒。
- vLLM eager模式，消息格式auto→openai，独立单卡副本，显存利用率0.55。
- 第1、2轮：GPU3、两路任务；第1轮中断恢复，跨两次服务。第3轮：GPU2和GPU3，每卡两路，共四路。GPU均与其他任务共享，硬件、调度及背景负载并不完全相同。
- 相同seed不代表逐字确定性；这些结果是实际运行的一致性比较，不能单独归因于采样随机性或某张卡。[原始参数和模型/源码哈希](configuration.json) 可核对方法是否一致。

## 轨迹公开范围

共公开378份脱敏代理轨迹，保留原生步骤顺序、系统提示、模型消息/思考、工具调用与返回、指标，以及378份模型生成的候选补丁。每轮3道排除题各有独立 `not_scored` 事件，没有伪造模型轨迹。

初始用户题面原文替换为明确占位符，并保留原消息SHA256和长度；私有主机路径、服务器地址和凭据模式被脱敏。模型及工具输出可能引用问题片段或公开仓库代码；它们是执行内容，不是参考答案。未公开原始题目包、reference/gold/test补丁、权重、凭据或重复的完整HTTP消息历史。每题request metadata保留时间、采样、usage和来源哈希，共9920条请求记录；完整消息在代理轨迹中只保留单份执行内容，不重复发布逐次请求历史。

`trajectory-index.json` 分别记录服务器原始字节SHA和公开文件SHA。脱敏后的文件不冒充原始字节；未脱敏原始文件仍保留在服务器。本次公开轨迹是对历史批次只公开哈希清单范围的明确扩展。
