## Original versus published hashes

`original-source-hashes.json` describes the source bytes exported from the server. `published-source-hashes.json` additionally records the bytes published after personal paths and the server address were replaced with portable placeholders. They intentionally differ where `path_sanitized` is true. Runtime manifests that contain source fingerprints refer to the original executed bytes unless explicitly marked otherwise. Runtime source-code integrity constants remain intact; do not pretend a redacted snapshot is byte-identical to a historical run.
