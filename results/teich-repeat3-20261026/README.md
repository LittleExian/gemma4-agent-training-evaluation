## 模型和运行参数

- `TeichAI/Gemma-4-31B-Fable-5-Agent-Distill`，Gemma4架构，磁盘BF16权重，vLLM在线FP8，无LoRA。
- 三轮均seed42、top-k64、temperature0.2、top-p0.95、thinking6000、最大输出8192、上下文32768。
- 每题15分钟、56次工具调用、160轮；工具超时240秒、官方验证超时300秒。
- vLLM eager（没有CUDA graph），消息格式auto→openai，TP1独立副本，显存利用率0.55。
- 第1轮前102次原始生成在GPU2/3、每卡2路（共4路）；其中101题正常结束，另1题上下文超限。剩余24题在GPU0/2/3、每卡4路（共12路）生成。第2、3轮全程三卡每卡4路。
- 第1轮跨中断和并发调整，不能视为完全相同硬件条件下的确定性实验。相同seed也不保证逐字相同。[配置与来源哈希](configuration.json) 保留运行差别。

## 上下文异常与验证

仅第1轮 `rich_3782` 出现 `agent_context_limit`：24577输入加8192请求输出超过32768上下文。保留17次原LLM调用、21条请求记录和原始空候选补丁；之后仅重新执行官方验证，24项通过、1项目标测试失败，最终按未解决计分。没有重新生成补丁；没有把它记为超时或基础设施失败。第2、3轮没有该异常。详见其 [轨迹](round-1/traces/rich_3782.json) 与 [结果](round-1/results.json)。

## 公开范围与复核

公开378份脱敏模型/工具执行轨迹、378份生成候选补丁、378份请求元数据文件（共14090条请求），以及9条排除事件。轨迹保留系统提示、模型思考/消息、工具调用与返回、时间和token指标。初始用户题面替换为明确占位符，保留原文SHA256和长度；私有路径、用户名、主机地址和凭据模式被脱敏。模型/工具输出可能引用问题片段和公开仓库代码。

未公开原始题目包、参考/gold/test补丁、隐藏官方测试输出、权重、凭据或重复的原始HTTP消息历史。候选补丁是模型输出，不保证正确。原始服务器SHA与公开文件SHA分别记录，脱敏文件不冒充原字节。排除题只有not_scored事件，不伪造模型轨迹。

[导出验证](export-validation.json)、[综合校验](VALIDATION.json) 和 [发布清单](PUBLICATION_MANIFEST.json) 可用于核对。统计可用Python标准库复现：在 [analysis](analysis/) 目录执行 `python3 compare.py`。本次归档没有重新运行模型，判分沿用各轮已保存的官方验证结果。超时数和通过数分别统计。

与v2的 [观测比较](COMPARISON_TO_V2.md) 同时列出模型、预算和并发差别，不能作为受控因果结论。
